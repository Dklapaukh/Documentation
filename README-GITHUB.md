# Paramedic Notes — GitHub upload package

31 October 2026. Production app: paediatric IV tables blue, IM tables amber; remaining EAS medicine dose controls and enoxaparin SC table selection.

1. Extract this ZIP.
2. Upload all extracted files and folders to your GitHub repository root. Keep the folders intact. Upload the contents, not the ZIP.
3. For GitHub Pages: Settings → Pages → Deploy from a branch → select your branch and / (root).

No build command is needed. index.html is at the repository root. The app contains the same runtime files as the published Site. Keep .nojekyll if your upload method includes it.

The handover and release notes are in docs/. The complete editable Site source and retained CPG sources remain in the canonical Site repository; this ZIP is the generated deployment package.
