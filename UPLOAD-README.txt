UPLOAD
1. Extract this ZIP on your computer. Do not upload the ZIP itself.
2. Upload the extracted files and folders to the root of your existing GitHub Pages publishing folder, replacing matching files. Keep the arrest-pocket folder intact.
3. Ensure index.html is directly in the publishing folder, not inside an extra enclosing folder.
4. GitHub Settings > Pages: deploy from your branch and the publishing folder (usually main / root).

There are 61 files, below the 100-file web upload limit. No installation or build is required.
.nojekyll disables Jekyll processing; include it if your file browser shows it.

SCOPE
This is the production package. Full NZCPG source documents and extraction scripts are intentionally excluded; they remain in the canonical source repository. The deployed reference panels remain myocardial ischaemia, Falls and Ankle Injury from the retained version 16 content.

This package does not include patient data, credentials or the hosted Site access gate. GitHub Pages access is controlled by your GitHub configuration, independently of the ChatGPT-hosted Site.
